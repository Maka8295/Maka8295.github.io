Keyboard · Hall effect · Working daily driver

Lucca 58HE

A 58-key hall effect split keyboard. Every key sits over a DRV5053 analogue hall sensor, read through an ADG732 32-channel multiplexer into the RP2040's ADC. Measured travel resolution is about 7 µm, which makes rapid trigger and adjustable actuation from 0 to 3.5 mm possible in firmware.

  • MCU Waveshare RP2040-Zero per half
  • Sensing DRV5053 hall sensors via ADG732 mux
  • Lighting SK6803 Mini-E per-key RGB + 10-point underglow
  • Link USB-C, SPI or UART between halves
  • Extras SSD1306 OLED, 3D-printed case, KMK firmware

Debug tool · USB to JTAG / SPI / I2C / UART

FT2232H Breakout with Level Shifting

A dual-channel FT2232H breakout for poking at other people's hardware. Both channels pass through SN74LVC8T245 level shifters, so the target side can run at 1.8, 2.5, 3.3 or 5 V by flipping a DIP switch. A hardware isolation switch lets you detach a chip clip from the target without unplugging anything, and DIP-selectable 4.7 kΩ pull-ups make I2C work on either channel.

  • Bridge FTDI FT2232HL, USB-C
  • Shifting 2× SN74LVC8T245, selectable VTARGET
  • Power LDK130 1.8 / 2.5 V, AP2112K 3.3 V
  • Protection USBLC6-2 ESD on USB

Keyboard · Mechanical switches

Lucca58

The mechanical-switch sibling of the 58HE. Same 58-key split footprint, but with conventional hot-swap switches instead of hall sensors, which makes it a much simpler and cheaper build. Two PCB variants exist: a columnar layout and a row-staggered one.

  • Layouts Columnar and row-staggered variants
  • Connector USB-C
  • Fabrication JLCPCB-ready production files included

Wireless · ESP32-S3

Lazy Kiwi

A compact ESP32-S3 board with its own PCB antenna, external PSRAM and flash, and a USB-C port straight into the chip's native USB. It is laid out to be a drop-in wireless brain for other projects, with boot and reset buttons on board.

  • SoC ESP32-S3 with onboard PCB antenna
  • Memory ESP-PSRAM64H (8 MB) + W25Q128 (16 MB) flash
  • USB USB-C with USBLC6-2 ESD protection

Retro · Console re-engineering · In progress

SFFSFC

A small-form-factor re-engineering of the Super Famicom revision 2 motherboard. The original two-layer board is being redrawn on four layers with HDMI and TOSLINK outputs integrated, so a stock SFC chipset can drive a modern display without an external scaler. Currently in schematic capture.

  • Target SFC / SNES revision 2 chipset
  • Stackup 4 layers
  • Outputs HDMI video, TOSLINK audio
